 # VK Chatbot

Юридический чат-бот для ВКонтакте. 

Ссылка на сообщество https://vk.com/club239338333

## Функционал
- Правовой калькулятор (госпошлина + пени ЖКУ)
- Правовой конструктор (судебные документы)
- Обратная связь с сохранением в БД

## Установка
1. `pip install -r requirements.txt`
2. Заполнить `.env` (VK_GROUP_ID и VK_ACCESS_TOKEN)
3. `python main.py`
